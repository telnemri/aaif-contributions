# AAIF contributions

## Agent skills

### Issue tracker

Use GitHub Issues in `telnemri/aaif-contributions` for all personal planning. Read `docs/agents/issue-tracker.md` before tracker operations. Use explicit repository arguments. Upstream issues hold only contribution coordination and submitted work.

### Triage labels

Use the default labels. Read `docs/agents/triage-labels.md` for triage.

### Domain docs

Use a single context. Read `docs/agents/domain.md` before specifications or implementation.

## Publication

Open upstream PRs in draft mode. Prepare substantive review comments for Tamer before posting. Record AI assistance. Preserve exact source SHAs and check outcomes.
